# Restaurant Point of Sale System

A full-stack point-of-sale (POS) system built for restaurant operations, covering billing, order management, table tracking, menu management, and inventory — with a real-time kitchen order workflow.

## Overview

This system connects front-of-house staff (taking orders, managing tables, billing) with the kitchen in real time. When an order is placed, it's sent directly to the kitchen display, where the chef updates its status from **Preparing** to **Ready**, keeping both sides of the restaurant in sync without manual communication.

## Features

- **Billing** — generate and manage customer bills
- **Order Management** — create and track orders from placement to completion
- **Table Tracking** — manage table status and assignments
- **Menu Management** — add, edit, and organize menu items
- **Inventory Management** — track stock used in food preparation
- **Kitchen Display Workflow** — chefs
